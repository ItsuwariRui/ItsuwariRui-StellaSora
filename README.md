# ステラソラ 星ノ塔カウンター

9個の独立したカウンターを備える、外部ライブラリー不要の静的Webツールです。

- Lv3素質の取得回数、＋2強化の使用回数と残り回数（コイン集計の対象外）
- 素質の再抽選回数（1回40コイン）
- 音符5個セットの購入回数（通常90／20%引き72／半額45コイン）
- 音符15個セットの購入回数（通常400／20%引き320／半額200コイン）
- 消費コイン合計 = 再抽選回数 × 40 + 各セットの購入回数 × 価格
- 目標コインの自由入力、差額 = 目標コイン − 消費コイン合計（超過時はマイナス）
- 全リセット（目標コインは保持）、＋／−・直接入力、ブラウザー内の自動保存
- PC・スマートフォン対応

研究効果は灰色の行、素質の再抽選は橙色の操作枠、音符セットの購入は紫色のグループ枠で区別します。音符は5個セット・15個セットに分け、各セット内を通常→20%引き→半額の順に表示します。価格と支出の単位はコインです。

幅960px以上では2系統を横並びにして各3列（計6列）、480〜959pxでは系統を縦に並べて各3列、それ未満では各価格をコンパクトな行で表示します。ウィンドウの幅と高さに合わせて余白・文字・ボタンを調整します。

## 研究効果と集計対象

難易度8以上で対応する研究を解放した場合の上限として、Lv3素質は10回、＋2強化は5回を表示します。数えるのはLv3素質を実際に取得した回数と、＋2強化を使用した回数です。上限を超えた既存の保存値も切り捨てず、残り0回と超過回数を表示します。

合計に含まれるのは素質の再抽選と音符セットの購入だけです。素質購入・強化マシン・イベントでの支出、および探索中の収入を含めた所持コイン残高ではありません。

## 使い方

`dist/index.html`をブラウザーで開くだけで使えます。保存領域が制限された環境でも、カウント・計算は動作します。自動保存は同じブラウザー・URLで使用する場合に有効です。

HTTPサーバーで使う場合:

```sh
python3 -m http.server 8000 --directory dist
```

回数・目標コインは0以上の整数です。JavaScriptが正確に扱える整数の範囲を超える入力・合計は受け付けません。全リセット時に確認ダイアログは出ません。

## 検証

Node.js 18以降で、依存関係をインストールせずに実行できます。

```sh
npm test
```

`dist/counter.js`が計算と入力検証、`dist/app.js`が画面操作と保存、`dist/styles.css`が表示を担当します。
